# Community public entry manual test

1. Enable public Community for a dedicated test tenant only.
2. Browse the public Community entry while signed out; confirm no posting, commenting, reacting, RSVP, or provider-contact action is available.
3. Submit a join request with email, name, locality, and reason. Confirm one pending private request is created and duplicate pending requests are rejected.
4. Submit public feedback with each supported category and optional contact email. Confirm it does not appear in the feed or create a membership.
5. Approve a join request from Community Administration and confirm only Community enrollment is created.
6. Confirm Transportation roles, memberships, and sessions are unchanged. Restore the test tenant settings afterward.
